# Owners

Who owns what. This is a **record**, not an enforcement mechanism.

Governance in this product is the Git host's repository permissions and
nothing else: this Hub is private and closed to builders, so no builder can
change a guardrail, a skill, an agent rule, or this file — not because a gate
refuses them, but because they hold no access. That is the whole story, and it
is the version that survives on a plan with no protected branches, no
`CODEOWNERS` enforcement, and no required reviewers.

This file is not pushed to project repositories. It is here so that a person,
and `review`, can answer "who decides this?" without asking.
